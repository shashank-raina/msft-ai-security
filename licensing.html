The money question

What licences
actually gate what

Licensing runs on three independent axes, and movement on one never implies coverage on another. Nearly every AI security budgeting error I've been asked to untangle was one of two assumptions: that an M365 purchase covers Azure AI workloads, or that Agent 365 includes the Sentinel data lake. Neither is true.

The grid

Pick what you hold; watch what lights up

Every capability below sits on one of the five asset classes and is tagged see, govern, protect or detect, with the licence that gates it. Toggle what you actually hold — a selection lights everything it includes (E7 lights Agent 365 and E5; E5 lights E3, Defender for Endpoint P2 and the Purview suite). WHAT DO YOU HOLD?

Chips in lighter blue are included by something you selected. Prices are deliberately absent — never quote one from a web page, including this one.

* Purview PAYG is Purview's pay-as-you-go billing model: consumption-metered against an Azure subscription instead of per-user seats. It exists because agents and custom AI apps hold no seat licence — their data protection is billed by use. It's how the Foundry "Powered by Microsoft Purview" toggle is paid for without Agent 365, which is why the two Foundry-Purview capabilities above light from either chip.

⚠ One table, two populations, two licences

AgentsInfo — local agents populate on Defender for Endpoint P2 (included in E5) with no Agent 365 licence; cloud agents need Agent 365. CloudAppEvents — Copilot interaction verdict rows (Jailbreak, XPIA) arrive on E5; the Agent 365 runtime rows (InvokeAgent, InferenceCall, ExecuteToolBy*) do not exist until Agent 365 instruments an agent. When a screen shows nothing, check the licence gate before declaring a data gap — the Agent Telemetry Map carries the gate on every table for exactly this reason.

📌 Reading the grid honestly

A lit capability means the licence entitles you to it — it says nothing about whether it's deployed, configured, or covering the agents you think it covers. "Enabled" and "covered" are different claims. Entitlement boundaries follow the Agent 365 service description and Microsoft Learn as of early September 2026; the split moves, so re-verify before purchasing decisions. And never quote a price from a web page — verify against the current Microsoft price list.
